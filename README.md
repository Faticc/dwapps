# Программы для DwOS

Три вещи в одной папке — то, что стоит на машинах в мире, а не запускается
ради интереса:

* **bank** — банкомат: снять деньги со счёта предметом и внести обратно.
  Киоск: выхода нет, Ctrl+Alt+C его не убивает, через полминуты без
  касаний экран сам возвращается к заставке. Со счётом разговаривает
  сервер, через командный блок.
* **admins** — мод-состав: кто в какой группе и когда заходил в последний
  раз. Без входа в управление это табло, которое обновляется само; с
  входом — окна, где состав правят.
* **cbtest** — показать, что именно сервер отвечает на команду. Нужен,
  когда bank или admins его не поняли: коды цвета `§` выводятся как `&`,
  видно ответ как есть.

Рядом лежит `lib/mcsrv.lua` — разговор с сервером одним местом: баланс,
выдача и изъятие предметов, последний заход. Ответы сервера приходят
куском чата, и их разбор — самое хрупкое место; в библиотеке он собран
так, чтобы программы о нём не знали. Сами bank и admins пока носят свой
разбор внутри, перевод на неё — следующий шаг.

Интерфейс у обоих перерисован под DwOS: экран — пиксельный холст `gfx`,
где полублок делит ячейку на две точки, кадр собирается в видеопамяти, а
на экран уходит только изменившееся.

## Поставить

В игре, на машине с интернет-картой:

```
wget -f https://raw.githubusercontent.com/Faticc/dwapps/main/install.lua /tmp/a.lua && /tmp/a.lua
```

Программы лягут в `/home/dwapps`, а в `/bin` появятся ярлыки: `bank`,
`admins`, `cbtest` и `dwapps-update`. Дальше обновляться — просто:

```
dwapps-update
```

В DwOS то же самое быстрее делает `get`: `get install dwapps` (или по
имени программы — `get install bank`), потом `get update`. Состояние и
ярлыки у них общие.

Установщик помнит, откуда и куда ставил, качает только изменившиеся файлы
(в `manifest.lua` у каждого записаны размер и CRC32) и подменяет файл
только тогда, когда скачанное сошлось с манифестом, — оборванная загрузка
работающий банкомат не портит. `dwapps-update --dry` покажет, что
изменится, ничего не трогая.

Библиотеки ставятся не в системный `/lib`, а в `lib/` рядом с
программами: их каталог ярлык сам дописывает в `package.path`. Поэтому
вся установка — одна папка и несколько ярлыков, и снести её можно, не
разбираясь, чей `mcsrv.lua` лежит в системе.

## Что нужно машине

* **DwOS** — программы рисуют через `gfx`, в обычной OpenOS его нет.
* **командный блок** (`opencb`) — без него они запустятся, но денег и
  заходов игроков не увидят: спрашивать не у кого.
* **экран** — банкомату хватает 49×24, admins просит 88×25, то есть
  видеокарту и монитор 3 уровня.

Чего не хватает, установщик скажет сразу, а не когда игрок подойдёт к
машине.
